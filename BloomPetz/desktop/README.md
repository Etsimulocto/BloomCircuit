# BloomPetz Desktop / Raspberry Pi App

Planned responsibilities:

- detect connected BloomPetz devices
- mirror the four-line OLED
- display Name and Type
- show full stat/history views
- archive unlimited `.bloompet` files
- restore archived pets to one of three device slots
- auto-back up pets when USB/charging connection is established
- edit one-line 16-character pet art
- provide diagnostics/service tools

Keep desktop backup/library behavior separate from ESP32 pet simulation logic.
