# Reaction Libraries

Human-editable text banks for pet sayings and reactions.

Planned files may include `idle.txt`, `happy.txt`, `sleepy.txt`, `hungry.txt`, `annoyed.txt`, `petting.txt`, `rapid_taps.txt`, `rare.txt`, and type-specific banks.

Keep lines short enough to work with the 16-character OLED strip and horizontal scrolling system.
