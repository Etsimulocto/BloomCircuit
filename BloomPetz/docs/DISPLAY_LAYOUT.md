# BloomPetz Display Layout

Target OLED: 128x64, treated as a fixed four-line interface with approximately 16 character cells per line.

## Home screen contract

1. pet art + side-scrolling saying
2. pet Name + live information/stat
3. one current action/event/interaction
4. A action / B menu prompt

Pet art is always one line high and at most 16 characters wide.

## Controls

- UP / DOWN = select
- LEFT / RIGHT = edit/change/page
- A = enter/perform
- B = back

Menus use one item per line and scroll vertically when there are more than four items.
