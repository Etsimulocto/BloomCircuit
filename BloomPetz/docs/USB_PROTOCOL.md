# BloomPetz USB Protocol

Protocol details are not frozen yet.

Required capabilities:

- device identity/version
- active slot and pet identity
- live four-line OLED mirror
- pet-state/status read
- export one pet
- import/restore one pet
- list three device slots
- backup acknowledgement
- integrity/error reporting
- diagnostics

USB connection should support automatic pet backup when the device is plugged into a PC/Raspberry Pi for charging.
