# HAPPY JARZ Desktop App v1.2.0

## OLED Art Studio

- Add an **OLED ART** tab to the Raspberry Pi/Windows controller.
- Edit 128×64 monochrome faces, emojis, icons and small screen graphics on an enlarged pixel canvas.
- Add pencil, eraser, fill, line, rectangle and circle drawing tools.
- Add Star, Heart, Diamond, Spark, Smiley and Flower stamps in three sizes.
- Add mirrored drawing, a device-size preview, undo/redo, named art library, and U8g2 C-header export.
- Save the local art library to `~/.happyjarz/art_library.json`; no device firmware or serial protocol changes.

Firmware remains **0.6.1**.
