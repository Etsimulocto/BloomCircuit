# BloomSaver — Glitter

BloomSaver is now a standalone HAPPY JARZ / BLOOMCORE **Glitter laboratory**. The old background visual modes and timed preset switching are gone. All complexity lives in one continuously generative glitter field, backed by a simple slow randomized color fade.

## Run on Raspberry Pi

```bash
cd ~/BloomSaver
python3 bloomsaver_pi.py
```

No npm or external Python packages are required.

## Glitter engine

Glitter is generated by moving emitters, attractors, repulsors, bursts, drift and field noise. Actors have their own lifetimes and movement styles, so the system keeps changing without stepping through a canned playlist.

The control panel exposes:

- glitter count
- emitters
- attractors
- repulsors
- speed
- drift
- swirl
- field noise
- attraction
- repulsion
- burst chance
- trails
- glow
- twinkle
- minimum and maximum glitter size
- glitter hue
- hue spread
- background fade speed
- background saturation
- background brightness

## Background

The background is intentionally simple. It slowly fades between randomized dark hues. It is not a preset system and does not switch the Glitter engine into another visual mode.

## Actions

- **Randomize** — generates a completely new Glitter configuration.
- **Mutate** — nudges the current Glitter configuration without replacing it with a preset.
- **Pause** — freezes the simulation.
- **Fullscreen** — toggles fullscreen.

## Saved presets

Saved presets are user-created Glitter configurations stored in browser `localStorage`. They do not auto-cycle.

## Keyboard

- `R` — randomize
- `M` — mutate
- `Space` — pause/resume
- `F` — fullscreen
- `H` — hide/show controls

The UI still auto-hides after five seconds of inactivity.
